# Informe del proyecto final

- `Informe_ServiDesk.docx`: informe editable (Word). Los **cuadros amarillos** indican la captura que va en
  cada lugar: reemplazar el contenido del cuadro por la imagen; el pie de figura está en la fila de abajo de la misma tabla y se mantiene. Estilo: el del informe del proyecto 1 (Times New Roman 11, tablas #182B4C, márgenes de 2,54 cm).
- `Informe_ServiDesk.pdf`: misma versión exportada (sin capturas todavía).
- `build_informe.js`: genera el .docx (`node docs/informe/build_informe.js`). Después, abrirlo en Word y
  actualizar el índice (clic derecho sobre el índice → Actualizar campos) antes de exportar a PDF.
