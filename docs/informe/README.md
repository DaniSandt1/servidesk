# Informe del proyecto final

- `Informe_ServiDesk.docx`: versión final del informe (Word), con todas las capturas de AWS y del frontend.
  Estilo: el del informe del proyecto 1 (Times New Roman 11, tablas #182B4C, márgenes de 2,54 cm).
- `Informe_ServiDesk.pdf`: la misma versión final exportada a PDF (la que se entrega).
- `build_informe.js`: genera el texto del informe en un .docx nuevo con **cuadros amarillos** donde van las
  capturas (`node docs/informe/build_informe.js`). Sobrescribe `Informe_ServiDesk.docx`: usarlo solo para
  rehacer el informe desde cero. Después, abrirlo en Word y actualizar el índice (clic derecho sobre el
  índice → Actualizar campos) antes de exportar a PDF.
